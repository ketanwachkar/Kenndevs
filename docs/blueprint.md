# **App Name**: NebulaCode

## Core Features:

- Homepage Showcase: Visually striking hero section with company mission and service highlights.
- Animated Service Cards: Detailed service offerings with descriptions and animated service cards.
- Contact Module: Interactive and visually appealing contact form with social media links.
- Blog Display: Clean layout for company updates, tech insights, and industry trends.
- Responsive Layout: Responsive design ensures optimal viewing experience on all devices.
- Glassmorphism UI: Application of frosted glass effects with blur, transparency, and vibrant borders to UI elements.

## Style Guidelines:

- Primary color: Deep blue (#283593) for a modern, trustworthy feel.
- Background color: Dark gray (#121212) to create a sleek, dark theme.
- Accent color: Neon purple (#BB86FC) to highlight interactive elements.
- Body text: 'Inter' (sans-serif) for a modern, clean readability.
- Headline text: 'Space Grotesk' (sans-serif) for a futuristic and bold look.
- Use Heroicons for consistent and modern icons.
- Subtle fade-in, slide-in, and parallax effects for smooth transitions using Framer Motion.
- Animated CTA buttons with gradient hover effects for better engagement.
- Sticky header with clean navigation and mobile-friendly hamburger menu.
